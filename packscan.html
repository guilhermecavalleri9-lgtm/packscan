⚠️ Sua chave do Google está com problema
Como resolver sua chave do Google
1. Ative o faturamento (billing)
O Google exige um cartão cadastrado, mesmo pra usar de graça (dentro da cota não cobra nada).
→ Acesse console.cloud.google.com/billing → Vincular conta de faturamento → adicione um cartão.
2. Ative a "Geocoding API"
É a API que transforma endereço em coordenada.
→ Acesse este link da Geocoding API → confira que está o projeto certo no topo → clique em ATIVAR / ENABLE.
3. (Se necessário) libere a restrição da chave
Se a chave tiver "restrição de site/referer", ela não funciona no servidor.
→ APIs e Serviços → Credenciais → clique na sua chave → em Restrições de aplicativo escolha Nenhuma → Salvar.
✅ Depois de fazer isso, avise o administrador pra revalidar sua chave. Assim que ela ficar ativa, o aviso e o bloqueio somem automaticamente.

🔑 Minhas chaves de API
No plano de R$ 24,90/mês você usa a sua própria chave do Google — assim você tem 10.000 buscas grátis por mês direto do Google e não gasta créditos aqui. Cole sua chave abaixo. Não sabe pegar? Siga o passo a passo mais embaixo. 👇
Sem esta, o sistema usa um leitor simples de endereço (funciona bem na maioria dos casos).
⏱ Leva ~10 minutos na primeira vez. Você vai precisar de uma conta Google (a mesma do Gmail) e de um cartão (o Google pede pra cadastrar, mas não cobra dentro das 10.000 buscas grátis/mês).
1. Abra este link e entre com sua conta Google:
console.cloud.google.com
2. No topo da tela, clique em "Selecionar projeto" → "Novo projeto" → dê um nome qualquer (ex: "PackScan") → Criar. Espere uns segundos e selecione esse projeto.
3. Cadastre um cartão (o Google exige pra liberar). Clique no menu ☰ (canto superior esquerdo) → "Faturamento" / "Billing" → siga pra adicionar forma de pagamento. Fique tranquilo: dentro das 10.000 buscas/mês é gratuito.
4. Ative a API de mapas. No campo de busca lá em cima, digite "Geocoding API", clique nela e aperte "Ativar" / "Enable".
5. Agora crie a chave. Busque por "Credenciais" / "Credentials" → botão "Criar credenciais" → "Chave de API". Vai aparecer um código começando com AIza...
6. Copie esse código e cole no campo "Chave do Google" aqui em cima. Clique em 🔍 Testar chave — se aparecer ✓ funcionando, clique em 💾 Salvar. Pronto!
💡 Dica: se o teste falhar dizendo algo sobre "billing", volte no passo 3 (cartão) e no passo 4 (ativar a Geocoding API). São os dois esquecimentos mais comuns.
